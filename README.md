# Foodapp-full-stack


A modern and scalable Food Ordering & Delivery Application built using Spring Boot (Backend), React (Frontend), Stripe (Payments), AWS (Deployment), JWT Auth, and Role-Based Access Control.

 I built it from scratch to learn real-world full-stack development, payment integration, and cloud deployment.

🚀 Features

✅ User Authentication & Authorization

Secure JWT-based login & registration

Role-based access: Admin, Customer

💳 Stripe Payment Integration

Real payment processing in test mode

Secure checkout flow

📩 Custom Email Notifications

Automatic order confirmations & payment status updates

☁️ AWS Deployment

Backend on EC2

Database on RDS

Media & assets on S3

Deployed for real-time production use

🧰 Robust Backend (Spring Boot)

Spring Security for authentication & authorization

RESTful APIs for orders, users, menu, and payments

JPA + MySQL integration

🖥 Modern Frontend (React)

Responsive design with reusable components

Real-time order management

Smooth user experience for customers & delivery agents

📊 Admin Dashboard

Manage menu, orders, users, and deliveries in one place
